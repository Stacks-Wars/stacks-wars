## Connect Your Wallet

Stacks Wars supports two main wallet extensions for the Bitcoin ecosystem. Choose the one you're already using, or install one if you don't have it yet.

### Supported Wallets

#### Leather Wallet
Leather is the recommended wallet for Stacks. It provides native support for Stacks tokens (STX) and smart contracts.

**Steps:**
1. Visit [leather.io](https://leather.io) and install the browser extension
2. Create a new wallet or import an existing one
3. Save your 12-word recovery phrase in a safe place
4. Return to Stacks Wars and click "Connect Wallet"
5. Approve the connection in your Leather extension

#### Xverse Wallet
Xverse is a multi-chain wallet that supports Bitcoin, Stacks, and other chains.

**Steps:**
1. Visit [xverse.app](https://xverse.app) and install the browser extension
2. Complete the onboarding process
3. Add the Stacks network if prompted
4. Return to Stacks Wars and click "Connect Wallet"
5. Approve the connection in your Xverse extension

### Network Configuration

Stacks Wars operates on the **Stacks Mainnet** by default. Ensure your wallet is configured to use:

- **Network:** Stacks Mainnet
- **RPC Endpoint:** Official Stacks node (auto-configured by wallet)

For testnet development, some features may be available on Stacks Testnet, but real STX wagers only work on Mainnet.

### Getting STX Tokens

Before you can wager on games, you need STX tokens in your wallet.

#### Buy STX
1. Use exchanges like [Coinbase](https://coinbase.com), [Kraken](https://kraken.com), or [OKX](https://okx.com)
2. Send STX to your Leather or Xverse address
3. Confirm the transaction completes (typically 5-15 minutes)

#### Earn STX
- Win Stacks Wars tournaments
- Claim your payout rewards
- Participate in mining pools

### First Deposit

1. Navigate to "Deposit" in the Stacks Wars dashboard
2. Enter the amount of STX you want to deposit
3. Confirm the transaction in your wallet
4. Your balance updates instantly once confirmed

### Security Tips

- **Never share your recovery phrase** with anyone, including Stacks Wars staff
- **Use a hardware wallet** like Ledger for large amounts
- **Enable 2FA** if your wallet extension supports it
- **Verify addresses** carefully before sending transactions
- **Use testnet first** if you're new to Stacks

### Troubleshooting

**"Wallet not detected"**
- Ensure your wallet extension is installed and enabled
- Try refreshing the page
- Check that your browser supports the extension

**"Network mismatch"**
- Confirm your wallet is set to Stacks Mainnet
- Some wallet updates require reconnecting

**"Transaction pending"**
- Stacks transactions typically confirm within 5-15 minutes
- Check the [Stacks Explorer](https://explorer.stacks.co) for your tx hash

**"Insufficient balance"**
- Make sure your deposit has confirmed on-chain
- Accounts take 1-2 blocks to reflect new deposits
