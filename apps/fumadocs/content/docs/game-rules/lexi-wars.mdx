# Lexi Wars

Lexi Wars is a fast-paced word elimination game where players compete to be the last one standing.

## Objective

Survive rounds of word challenges by correctly answering prompts faster than your opponents. The last player remaining wins the pot.

## Game Setup

- **Players:** 2-8 players per game
- **Round Time:** 30-60 seconds per round (depends on lobby settings)
- **Lives:** Each player starts with 3 lives
- **Total Rounds:** Best of 5, 7, or 11 rounds

## How to Play

### Round Structure

1. **Prompt Appears** - A category and starting letter are displayed
   - Example: "Animals starting with 'D'"
   - Example: "Movies from the 2000s starting with 'T'"

2. **Submit Your Answer** - Type a valid word matching the prompt
   - Must match the category and starting letter
   - Cannot be a proper noun (unless specified)
   - Each answer can only be used once per game

3. **Server Validation** - The system checks answers in real-time
   - Valid answers are confirmed with a checkmark
   - Invalid answers show a red X

4. **Elimination** - Players who don't answer in time lose a life
   - The timer counts down visibly
   - Last second submissions are allowed

5. **Next Round** - A new prompt appears for surviving players

### Elimination Rules

- **Time Expired** - If you don't submit an answer before the timer ends, you lose 1 life
- **Invalid Answer** - Submitting a word that doesn't match the category or letter costs 1 life
- **No Response** - If you're AFK (away from keyboard) for 2 consecutive rounds, you're eliminated
- **Game Over** - When you lose all 3 lives, you're out and win is calculated by your placement

## Word Validation

The word checker uses a comprehensive dictionary including:

- Common English words
- Modern slang and internet terminology
- Brand names (if they've become common words, e.g., "google")
- Plural forms and past tenses
- Words from all English dialects (US, UK, Australian, etc.)

> **Excluded:** Proper nouns, abbreviations, single letters, numbers, and non-English words

## Strategy Tips

**Speed Over Perfection**
- First correct answer wins the round
- Common answers beat obscure ones (less chance of duplication)

**Avoid Common Words**
- If many players submit "Dog" for animals, you're all safe
- Unique answers guarantee a point if correct

**Read the Prompt Carefully**
- Check the starting letter requirement
- Verify the category limits
- Some categories have tricky sub-rules

**Manage Your Lives**
- Don't take risky answers late in the game
- When ahead, play conservatively
- When behind, take calculated risks

**Watch Your Opponents**
- Note what words they've used
- Try to find different categories or letters
- Learn their answer patterns

## Scoring

- **Round Win:** 1 point
- **Perfect Round** (answered in under 5 seconds): +1 bonus point
- **Final Victory:** Win the game for maximum payout
- **Leaderboard Points:** Wars Points based on your placement

## Common Questions

**Q: Can I use the same word twice?**
- No, each word can only be submitted once per entire game across all categories

**Q: What if two players submit the same answer?**
- Both get the point and the round continues (no elimination)

**Q: Can I use brand names?**
- Only if they've become generic terms (like "kleenex" or "band-aid" in some regions)

**Q: Are abbreviations allowed?**
- No abbreviations (USA, FBI, etc.) or acronyms

**Q: How long do I have to answer?**
- Depends on difficulty: Easy (60s), Medium (45s), Hard (30s)
